# Self-Storage-CRM

CRM-панель управления сетью контейнерных кладовок.

## Структура проекта

- `backend` - Laravel REST API
- `frontend` - React SPA

## Стек

- **Backend:** PHP 8.5, Laravel 13, PostgreSQL, Sanctum
- **Frontend:** React, JS, HTML/CSS

## Команда

- **metasensitive** - Backend
- **Scam** - Frontend

## Установка

См. README в папках `backend` и `frontend`.
